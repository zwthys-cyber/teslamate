# 建筑区位地图（预览）

原生 MapLibre 6.31.0 使用内置 ArchitecturalMap.json 绘制底图，数据来自 OpenFreeMap / OpenMapTiles / OpenStreetMap。原有 Apple 地图可随时切换，样式选择在本机保留。

- 深蓝为主干路网，紫色为次干道，浅青为街道；深青白边线为真实行程，不再用底图道路颜色表示车辆速度。
- 灰色和桃色半透明圆分别表示出发和到达节点，是屏幕大小固定的标记，不代表覆盖半径或商业分析。
- 水面、海岸、建筑及绿地逐层绘制。当前分析模式固定采用浅色纸面配色。
- 地图服务会收到所浏览区域的瓦片请求和网络地址；TeslaMate 密钥、服务器地址和完整轨迹不会作为地图请求参数发送。轨迹仅在设备上叠加。
- 网络失败可以重试或切换 Apple 地图。不同区域的开放地图覆盖程度可能不同。
- 当前是视觉验收预览；尚未替代正式版，未验证中国大陆网络环境。
